# Лабораторная работа № 5. Stream API, Gson и Lombok

**Автор:** Панфилов Евгений Павлович
**Группа:** ФИТ-251

## Описание
Программа читает данные о посетителях библиотеки из файла `books.json`, обрабатывает их с помощью Stream API, использует Gson для парсинга JSON и Lombok для автоматической генерации стандартных методов классов.

## Выполненные задания
1. Выведен список посетителей и их количество
2. Выведен список книг без повторений
3. Книги отсортированы по году издания
4. Проверено наличие книг автора Jane Austen
5. Найдено максимальное число книг у одного посетителя
6. Сформированы SMS-сообщения для подписчиков с группировкой по категориям

## Как запустить

### Требования
- JDK 25
- Maven 3.6+
- IntelliJ IDEA (рекомендуется)

### Запуск через IntelliJ IDEA
1. Откройте проект в IntelliJ IDEA
2. Дождитесь автоматической загрузки зависимостей Maven
3. Откройте класс `Main.java`
4. Нажмите зелёную кнопку запуска (Run) рядом с методом `main`

### Запуск через командную строку
```bash
# Сборка проекта
mvn clean compile

# Запуск программы
mvn exec:java -Dexec.mainClass="Main"
